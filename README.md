# -HW-Patches-Archive
About mod:
The patch archive is a mod created as part of the HM program within Harmony Workshop; its purpose is to implement compatibility fixes for mods that previously could not work together or worked but not fully.

(relevant for version 1.16.10)Patches: 
Sable - A patch for correct rendering and creation of portals in the nether and the undead do not burn in the sun when they are beneath physical objects.

SecurityCraft - compatibility patch for immersive portals.

Sodium - The correct display of several portals in immersive portals has been fixed.

Immersive Portals - Compatibility and optimization patches.

Enhanced AI - The undead no longer attack vampire players.

Legendary Survival Overhaul - Mechanics work with sable objects.

Vampirism - Vampires do not take damage from the sun while under physical blocks.

Voxy - At the moment, it doesnt quite work as intended, but at least all possible causes of the game crashing have been eliminated (the ones I managed to find, of course).

Simple Voice Chat - Now the sound should be transmitted through.

Alex Mob's - When launching three mods(sable, immersive portals and alex mobs), an error occurred that caused the game to crash; it has now been fixed.
Other patches will be added as needed.



P.s: You don’t have to install all the mods; I did this based on the assumption that not everything will be installed.
